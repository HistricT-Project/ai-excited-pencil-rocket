A giant pencil rocket escapes its notebook and shouts WOW, JUDGE! at the judge — one 1024×1024 PNG, drawn procedurally by a Node 22 program using only the standard library. No image assets, no network, no randomness beyond a fixed seed: the program draws the sunset sky, the pencil rocket, its flame and scribble trail, and the shout, then encodes the PNG itself.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
